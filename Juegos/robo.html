🟢 Nivel Básico - Fundamentos

Conceptos Clave:

  • Motor: Dispositivo que convierte energía eléctrica en movimiento
  • Sensor de Inclinación: Detecta cambios de posición
  • Sensor de Movimiento: Detecta objetos cercanos
  • Hub USB: Cerebro del sistema LEGO WeDo

🏗️ Prototipos para Huallanca:

1. Sistema de Riego Automático

Problema: Escasez de agua en cultivos de papa y maíz

Solución: Motor activa bomba de agua cuando el sensor detecta sequedad

2. Alarma para Corral

Problema: Depredadores atacan animales de granja

Solución: Sensor de movimiento activa alarma sonora

3. Puerta Automática de Establo

Problema: Dificultad para abrir/cerrar puertas con las manos ocupadas

Solución: Motor abre puerta al detectar presencia

4. Ventilador para Invernadero

Problema: Exceso de calor en cultivos protegidos

Solución: Sensor de temperatura activa ventilador

5. Medidor de Nivel de Agua

Problema: Control del nivel en reservorios

Solución: Sensor de inclinación indica nivel

🟡 Nivel Intermedio - Programación Condicional

Conceptos Avanzados:

  • Condicionales (SI-ENTONCES): Toma de decisiones en el programa
  • Bucles: Repetición de acciones
  • Variables: Almacenamiento de datos
  • Sensores Combinados: Múltiples entradas de datos

🏗️ Prototipos Intermedios:

6. Clasificador de Minerales

Problema: Separación de minerales en pequeña minería

Solución: Sistema con sensor de color y motor clasificador

7. Sistema de Alerta de Lluvias

Problema: Prevención de huaycos en temporada de lluvias

Solución: Sensor de humedad activa alarma preventiva

8. Brazo Mecánico para Carga

Problema: Carga de sacos de cosecha

Solución: Brazo robótico con múltiples motores

🔴 Nivel Avanzado - Sistemas Complejos

Conceptos Expertos:

  • Bucles Anidados: Estructuras de control complejas
  • Subrutinas: Modularización del código
  • Comunicación Serial: Intercambio de datos
  • Optimización: Eficiencia energética y de movimientos

🏗️ Prototipos Avanzados:

9. Vehículo Autónomo Agrícola

Problema: Transporte de productos en terrenos difíciles

Solución: Robot móvil con navegación autónoma y sensores múltiples

10. Estación Meteorológica Inteligente

Problema: Monitoreo climático para agricultura

Solución: Sistema completo con múltiples sensores y registro de datos
